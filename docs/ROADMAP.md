# Roadmap

1. Validate the current time, solar, Lagna, nakshatra, and pada pipeline with independent fixtures.
2. Replace provisional astronomy with a validated ephemeris and configurable conventions.
3. Add timezone identifiers and DST-aware conversion.
4. Add Panchanga and planetary positions.
5. Add Rasi and divisional chart rendering.
6. Add Vimshottari Dasha.
7. Add client records, persistence, exports, and PDF generation.
8. Add API security, offline packaging, localization, and end-to-end tests.
